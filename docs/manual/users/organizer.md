# 工程整理

工程整理操作的是 AE 工程面板中的素材目录结构。

## 整理一次工程

1. 在 AE 中打开要整理的工程，进入面板的工程整理页。
2. 选择整理方案，查看规则中的文件后缀和目标目录。
3. 根据工程需要配置合成、固态层和未匹配素材的全局目录。
4. 如有需要，在设置中添加要忽略的主合成名称。
5. 执行整理，检查面板结果与工程目录。

素材会直接移动到规则指定的目标目录，整理结束后清理空文件夹。执行结果可通过 AE 的撤销命令回退。

## 复用自己的规则

按文件后缀设置素材归类路径，再保存为自己的整理方案，供后续工程复用。内置默认方案随程序分发，自定义方案随个人数据保存。

方案有未保存修改时，才会显示保存和「放弃修改并还原」按钮。还原会恢复最近一次保存的名称及规则；内置方案恢复为预设，尚未保存的新方案则移除该草稿。未开启安静模式时会先确认，取消后保留全部修改；开启安静模式后直接还原。保存失败时仍保留草稿和两个操作按钮。

文件夹选择弹窗提供出现和消失动画，速度沿用设置中的「动画耗时倍率」。关闭动画或系统开启「减少动态效果」时即时显示、隐藏。

合成、固态层和未匹配素材的目录是全局设置；切换整理方案时也应核对这些设置。不同版本的规则编辑界面可能有所变化，请以安装版本为准。

## 整理前检查

- 确认当前 AE 工程就是目标工程。
- 核对文件后缀和目标目录，避免规则冲突。
- 重要工程先保存，再执行整理。

方案如何备份见[数据与备份](./backup.md)。
