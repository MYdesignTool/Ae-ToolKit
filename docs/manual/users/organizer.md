# 工程整理

工程整理操作的是 AE 工程面板中的素材目录结构。

## 整理一次工程

1. 在 AE 中打开要整理的工程，进入面板的工程整理页。
2. 选择整理方案，查看规则中的文件后缀和目标目录。
3. 根据工程需要配置合成、固态层和未匹配素材的全局目录。
4. 如有需要，在设置中添加要忽略的主合成名称。
5. 执行整理，检查面板结果与工程目录。

素材会直接移动到规则指定的目标目录，整理结束后清理空文件夹。执行结果可通过 AE 的撤销命令回退。

## 复用自己的规则

按文件后缀设置素材归类路径，再保存为自己的整理方案，供后续工程复用。内置默认方案随程序分发，自定义方案随个人数据保存。

合成、固态层和未匹配素材的目录是全局设置；切换整理方案时也应核对这些设置。不同版本的规则编辑界面可能有所变化，请以安装版本为准。

## 整理前检查

- 确认当前 AE 工程就是目标工程。
- 核对文件后缀和目标目录，避免规则冲突。
- 重要工程先保存，再执行整理。

方案如何备份见[数据与备份](./backup.md)。

## 0.5.1 的目录与方案编辑

目标目录使用可搜索目录树，支持逐级新建和完整路径粘贴。选择先保留在弹层会话，确认后写回路径框；选择目录本身不会立刻修改 AE 工程。双击目录或在目录列表中按 Enter 可直接选用，Escape 先取消当前表单再关闭弹层。

后缀及忽略合成名称按 Enter 生成可移除标签。忽略名称使用完整名称，保留名称内的空格；保存或整理前会检查后缀非法值和跨规则冲突。

内置预设另存为个人方案；个人方案可保存修改、重命名、复制或删除。未保存时切换方案会提示，保存失败保留草稿。全局目录与忽略名单独立即保存，不随方案草稿切换。
