# 普通用户指南

Ae-ToolKit 是面向 After Effects 2023 及更新版本的本地工具面板，把工程整理、批量表达式和本地脚本集集中在一起。Windows 使用原生 WebView2，macOS 使用 CEP。

## 第一次使用

1. 按照[安装与更新](./installation.md)安装扩展，重启 AE 并打开面板。
2. 在 AE 首选项「脚本与表达式」中启用「允许脚本写入文件和访问网络」。
3. 选择一个工作入口：整理项目素材、批量应用表达式，或设置常用脚本目录。
4. 使用一段时间后，通过设置页导出备份，或按[数据与备份](./backup.md)保存完整工作环境。
