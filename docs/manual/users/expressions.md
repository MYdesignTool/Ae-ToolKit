# 批量表达式

## 应用到选中属性

1. 在 AE 时间线中展开图层，选中位置、旋转等具体属性；仅选中图层不会选中其中的属性。
2. 进入批量表达式页，搜索并选择已有表达式，或清空选择后输入自己的代码。
3. 核对面板显示的选中属性数量。表达式页可见时会自动同步 AE 选择，也可手动刷新。
4. 点击「应用到选中属性」，或在编辑器中按 `Ctrl / Cmd + Enter`。
5. 查看底部状态栏的成功、跳过和失败数量。

已有表达式会沿用覆盖确认流程；安静模式沿用免确认设置。失败属性会尝试恢复原表达式；整批操作可在 AE 中一次撤销。

选择表达式的下拉列表中，名称靠左，标签以标签块靠右显示；收起后也保留相同布局。可用 ↑↓ 浏览、Enter 确认、Esc 收起；展开与收起动画跟随设置页的动画耗时倍率。

## 应用到图层的变换属性

1. 仅选中需要处理的图层，不选择具体属性。
2. 鼠标悬停在表达式页底部操作区右侧的「变换目标」上展开选择，勾选立即生效；移出按钮和选择面板后自动收起并保留勾选，无需额外确认。支持锚点、位置、缩放、旋转 / Z 旋转、不透明度，以及 3D 图层的方向、X/Y 旋转。默认全部不选；同次面板会话保留勾选，重载面板后清空，不随设置或备份保存。
3. 核对选中图层数量、实际可处理属性数量及已有表达式数量，点击「应用到图层变换」或按 `Ctrl / Cmd + Enter`。

2D 图层会跳过 3D 专属项，锁定或缺少对应属性的图层会跳过相应目标。位置已经分离维度时，会处理现有的各轴位置属性。清空全部目标时不会应用。

明确选中的具体属性始终优先；即使同时选中图层，也不会额外应用到其余变换。移除表达式遵循同一目标范围。覆盖确认、安静模式和整批一次撤销与原流程一致；确认后若 AE 选择或目标状态发生变化，会中止操作并提示重试。

## 编辑与保存

表达式编辑器支持行号、语法高亮、括号匹配、代码补全与自动缩进。点击编辑器下方的语法错误提示可跳到对应行列。

0.6.1 中，从输入第一个字母起就会尝试补全，输入 `wig`、`thisComp.` 或 `Math.` 等可进一步筛选。名称前缀优先，也支持驼峰或下划线词段前缀，最多显示最匹配的 7 个候选。使用 ↑↓ 选择，默认按 `Enter` 接受，可在「表达式编辑设置 > 接受候选按键」改为 `Tab`。未选为接受键的按键保持换行或缩进功能；函数自动添加括号并将光标放入括号内。不绑定 `Ctrl / Cmd + Space` 或 `Esc`。

选中内置函数时，底部显示简短功能说明、参数数量、每个参数的含义，以及必填/可选和默认值；存在多种调用方式时会分别列出。参数较多时可在说明区域滚动。设置页「表达式编辑设置」位于工程整理设置之后、脚本文件夹之前，其中「表达式代码补全」「表达式函数说明」均默认开启，可以分别关闭并记住选择。关闭说明后仍保留补全列表和简短签名。

内置属性会显示用途与值类型，例如 `audioActive` 说明音频开关及图层入出点条件。短说明不会占据大块空白区域。

候选支持常用 AE 对象成员、JavaScript 常用项及草稿变量。输入和删除字符时都会持续更新匹配结果，支持退格、Delete 及删除选区；删空后收起候选。词库与帮助完全离线，不读取工程内的实际图层或效果名称。注释、字符串及输入法选词期间不显示补全。

- 点击「格式化」或按 `Shift + Alt + F` 整理排版；格式化失败时保留原稿。
- 使用「另存为」创建自定义表达式；自定义条目可以保存修改或删除。
- 保存窗口中的标签输入后按 `Enter` 添加，点击标签旁的 × 移除；`Enter` 添加标签时不会提交窗口。可不填标签，取消会丢弃本次修改。
- 也可以从「选择已有标签」中选择内置或自定义表达式已有的标签，已添加的标签不会重复显示在可选列表中。
- 标签过滤可连续选择多个标签，结果须同时包含全部所选标签，并与名称搜索组合。已选标签显示为标签块，点击 × 移除，点击「清空」恢复全部标签。
- 切换条目时留意未保存提示。
- 补全弹层关闭时，`Tab` 插入两个空格；补全和格式化都可通过 `Ctrl / Cmd + Z` 一次撤销。

语法检查不会执行代码，也不会判断表达式是否适合选中属性。最终求值结果应在 AE 中确认。
