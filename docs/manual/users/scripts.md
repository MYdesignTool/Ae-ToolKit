# 本地脚本集

## 添加与运行

1. 在设置中选择自己的脚本目录。
2. 刷新脚本集，扫描目录中的 JSX / JSXBIN 文件，后缀不区分大小写。
3. 使用搜索和收藏查找常用脚本。
4. 双击条目运行，或通过键盘选中条目后按 `Enter`。

第三方脚本由 AE 执行，具有宿主脚本权限，请选择可信来源。

## 为脚本添加横幅

图片相对于所选脚本根目录查找，支持 PNG、JPG、JPEG、WebP、GIF。以 `Sub/Tool.jsx` 为例，匹配顺序为：

1. `image/Sub/Tool.png`：根目录 image 中保留子路径的同名图片。
2. `image/Tool.png`：根目录 image 中的扁平同名图片。
3. `Sub/Tool.png`：脚本旁的同名图片。

横幅按 4:1 比例显示，等比填充并裁切边缘。没有图片或加载失败时显示默认山景占位图。

## 扫描与迁移

`image` 和括号包围的目录不会作为脚本目录扫描。扫描上限为 24 层、20000 项，达到限制会提示。

将脚本放在 `AeLocalToolkit/scripts/` 内，再在设置中选择该目录，可以随扩展一起携带；同时复制脚本目录中的 `image`。扩展外的脚本需要另行复制，并在路径变化后重新选择目录。
