# 常见问题

## AE 中找不到面板

Windows 0.5.1 原生版从「窗口 → AE Local Toolkit (WebView2)」打开。确认安装器选择了当前运行的 AE；多个 AE 版本需分别安装。安装或更新后重启 AE，并检查 WebView2 Runtime 是否安装成功。

macOS 从「窗口 → 扩展」打开。确认 AE 为 2023 或更新版本、CEP 文件夹完整、对应 CSXS 开发模式正确；不要启用多个同 ID 副本，扩展路径不要包含井号。

完整步骤见[安装与更新](./installation.md)。

## 设置或预设无法保存

确认扩展内 `data` 子目录对实际运行 AE 的用户可写。若安装器使用了另一管理员账户提权，应为实际 AE 用户检查权限和开发模式设置。无须授予整个扩展程序目录写入权限。

先保留原数据再恢复，见[数据与备份](./backup.md)。

## 选了图层，表达式页仍提示没有选中属性

在时间线展开图层并选中具体属性，例如位置或旋转，再回到面板刷新选中状态。表达式作用于属性，而非图层本身。

## 表达式通过语法检查，AE 仍显示错误

语法检查不会执行表达式，也不能验证 AE 属性、宿主对象或计算结果。核对表达式与目标属性的维度、引用和适用范围，并以 AE 中的实际结果为准。

## 找不到脚本或横幅图片

先确认设置中选中了正确的脚本根目录，再刷新。脚本必须是 JSX / JSXBIN；`image` 和括号包围目录不会扫描。图片的同名匹配规则见[本地脚本集](./scripts.md)。

## 输入法候选窗位置异常

Windows 0.5.1 已使用原生 WebView2 处理微软拼音候选窗定位。先确认打开的是「AE Local Toolkit (WebView2)」，再记录系统、AE、扩展、输入法版本及出现问题的输入框。macOS 和历史 CEP 环境需按各自宿主复现；将信息提交到下方 Issues，避免套用另一平台的修复步骤。

## 如何反馈问题

到 [GitHub Issues](https://github.com/MYdesignTool/Ae-ToolKit/issues) 提供扩展版本、AE 版本、系统、复现步骤和面板提示。有 Debug 输出时可附上相关错误；分享前移除个人路径和工程信息。
