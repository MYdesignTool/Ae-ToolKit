# 设置

在设置页管理界面偏好、脚本目录与完整数据备份。设置会保存到当前安装的个人 JSON，重开面板后继续使用。

## 表达式编辑设置

此分组位于「工程整理设置」之下、「脚本文件夹」之上。

| 设置 | 作用 | 默认值 |
| --- | --- | --- |
| 表达式代码补全 | 输入或删除字符时显示匹配候选，最多 7 项 | 开启 |
| 接受候选按键 | 在 Enter 与 Tab 中选择一个接受键，补全框底部显示当前按键 | Enter |
| 表达式函数说明 | 显示所选候选的用途和参数用法 | 开启 |

以上设置立即生效，并随个人数据保存和备份。选择 Enter 接受时，Tab 保持缩进；选择 Tab 接受时，Enter 保持换行。关闭函数说明仍保留候选与简短签名。

图层「变换目标」的勾选属于当前面板会话，重载后恢复全部不选，不随这些设置保存。完整用法见[批量表达式](./expressions.md)。

## 界面语言

在「通用设置 → 界面语言」选择简体中文或 English，即时生效。语言切换保留表达式草稿、撤销历史与整理规则；用户名称、路径和表达式代码保持原文。

## 动画耗时倍率

0.5.1 起可设置动画耗时倍率：

| 设置 | 效果 |
| --- | --- |
| 0.5x | 更短的动画耗时 |
| 1x | 默认动画耗时 |
| 2x | 动画耗时为默认的两倍 |
| 关闭 | 关闭相关动画 |

系统启用「减少动态效果」时，面板会尊重该偏好。调整倍率改变的是动画耗时，不改变整理、表达式或脚本本身的执行结果。

下拉菜单、代码补全、变换目标及整理目录选择的展开和收起均使用同一套动画设置。

## 安静模式与 Debug

安静模式沿用免确认设置。启用前请理解覆盖表达式等操作的影响，执行后仍需检查状态栏结果。

方案「放弃修改并还原」在普通模式下先确认，安静模式下直接执行；错误提示仍会显示。

Debug 便于查看桥接与启动错误。反馈时只附相关错误，分享前移除个人目录和工程信息。启动失败时 Debug 可能临时显示，以便排查原因。
