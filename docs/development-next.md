用户授权保留 CEP 并完成独立分支移植。完整 CEP 开发状态保存为 `codex/cep-0.5.1-baseline` 的 `0a631c9`；新宿主在附加 worktree 的 `codex/webview2-migration` 开发。`native/toolkit/` 复用公共宿主，接入完整界面和全部 17 个业务方法，保留原 JSX 逻辑及备份格式。JSX 私有缓存、原生 profile、安装链接和一次性 CEP 数据副本均分离。

当前完整候选已构建并部署为独立 `AeltToolkitWebView2` 插件；原 CEP 和 Starfield 保留。最初 62 项逻辑检查、240 项原生队列检查、12 项桥接检查及实际生成 JSX 的假宿主检查通过；完整界面在新传输 mock 下通过整理/方案/脚本/表达式/标签/动画/双语/窄面板回归，原有 CEP 输入、编辑器和启动诊断回归通过。用户先确认完整界面及候选窗正常，随后确认整体验收、无可见故障。真实 AE 自动回归通过设置保存与恢复、方案增删、中文及字面百分号路径扫描、图片加载、临时脚本运行、选区读取和方法拒绝。实测发现并修正脚本模块的原生路径百分号解码问题，补强测试替身；当前工程没有改动，原 CEP 数据哈希不变。用户授权移除探针后，已只移除其核验过的安装 junction；已加载菜单将在下次 AE 启动时消失。

## 平台安装与固定依赖

Windows 安装源码已改为 AEGP AEX，目标为所选 AE 的 Support Files/Plug-ins/AeltToolkitWebView2；macOS 保留 CEP ZIP。共用一份 client/host 源码，平台暂存各一份，不在 Windows 附带另一个 CEP 安装，也不把 Windows 组件放进 macOS。原 CEP 回退版不自动停用或删除。数据、备份和 profile 不进入载荷；原生更新先备份，卸载保留数据及重装身份。安装适配发现并修正 profile 路径，新的无调试候选改用实际用户 LocalAppData，未在 AE 运行时替换当前已验收 AEX。

Starfield 的参考宿主已是当前仓库内的独立源码。此前需要从其目录读取的 SDK，以及所需 x64 编译工具链、NSIS、Node 和微软签名的离线 WebView2 Runtime 安装程序均已实体复制至当前 worktree 的 .local-deps；锁定版本和 SHA-256，默认构建不再访问 Starfield。构建输入不进入产品包，快照被 Git 忽略、需单独保留，见 [固定依赖](../native/build/README.md)。

上一阶段新增平台白名单和过期/调试 AEX 拒绝测试后共 64 项 Node 检查通过，只做了暂存和预处理；随后本轮自动发布实施补足了完整编译和隔离执行，见下节。

## 动画设置

设置 > 通用设置新增「动画耗时倍率」，切换后立即生效，随个人数据保存，可随备份导入、导出。

| 选项 | 动画时长 | 含义 |
| --- | --- | --- |
| 2x | 原版的 100% | 保持原有速度 |
| 1x（默认） | 原版的 50% | 比原版快一倍 |
| 0.5x | 原版的 25% | 更快 |
| 关闭 | 无动画 | 页面直接切换 |

倍率同时作用于 CSS 过渡、弹窗、整理进度、页面进出、收藏星标和粒子，包括错峰延迟。系统「减少动态效果」优先关闭动画，保留用户选中的倍率。旧设置没有此字段时默认 1x。关闭进行中的页面切换仍会完成导航。

## 表达式标签与筛选

- 名称搜索只匹配预设名称；内置预设同时匹配中文原名与当前显示名称，不区分大小写。
- 标签下拉可独立筛选；与名称同时使用时，预设必须满足两个条件。
- 「另存为」弹窗可输入名称和多个标签，标签用英文逗号、中文逗号或换行分隔，去除首尾空白和重复项，允许留空。
- 选择自定义预设后，点击「名称和标签」可修改名称及标签，保存时一并保存当前编辑区代码；「保存修改」沿用相同弹窗。
- 内置预设保持只读，可通过「另存为」保存个人副本并修改标签。
- 新预设不再自动写入「自定义」分类或标签。旧分类兼容为标签，保存、导入时合并已有标签并移除分类字段；清空标签后不会再次补回旧分类。
- 修改失败会保留已选预设和当前代码，取消弹窗不修改数据。筛选隐藏当前条目时保留编辑区草稿。

中文和 English 界面均已适配。在 360×520 小面板中压缩间距、隐藏重复标签摘要，标签仍显示在预设下拉项中，编辑器、语法提示与操作按钮保持可用。

## 输入法定位

**2026-10-21 独立 WebView2 原型。** 用户选择先做独立验证，并授权复用 Starfield 已有 AEGP + WebView2 宿主。现已抽取 [`native/panel-host/`](../native/panel-host/README.md)，以及独立使用方 [`native/input-probe/`](../native/input-probe/README.md)。身份、缓存、安装链接和内容目录与 Starfield/CEP 分离；当前 CEP 版本保持原样。用户在 AE 23.5 / 微软拼音确认三个输入区域的首次和连续输入、移动/缩放/浮动/停靠/焦点往返、英文、系统复制粘贴、撤销重做及测试快捷键均正常。随后按用户授权在新分支接入完整工具箱，并取得完整界面及候选窗正常的反馈，见本页顶部记录和 [评估](webview2-migration-assessment.md)。不发布、不生成安装器的约束继续有效。

**2026-10-21 逐项与组合复测。** TSF 禁用项继续保留；其余实验按用户反馈逐项切换或组合验收。当前组合、已排除项目及每轮结果统一记录于 [输入法说明](../extension/docs/ime-compatibility.md)，其余 0.5.1 功能保留。

文本回归覆盖 input、textarea 和当前 CodeMirror，但不能证明 Windows 候选窗已修复。本轮只改 JS，重载扩展即可。启动参数更改时需实际进程核查；本机观察到 AE 会在 CEP 进程重建后继续传入缓存参数，必要时才保存工程并重启 AE。

用户提供的 [CEF #3306](https://github.com/chromiumembedded/cef/issues/3306) 和[原生补丁](https://github.com/loongson/cef/commit/c9b8f03731c67ad3b3ef232c476cafe66da462b9) 指向 Windows HWND / WebContents 焦点顺序。该补丁需要在 CEF 原生层实现，当前扩展仓库没有 Adobe CEP 的可构建原生源码。不能将前端文本测试通过等同于微软拼音候选窗验收通过。完整证据和后续边界见 [输入法说明](../extension/docs/ime-compatibility.md)。

Adobe 已记录同类输入框候选窗左上角问题：[CEP-3029](https://community.adobe.com/questions-729/korean-ime-problem-in-cep-12-panel-1419911)。该记录针对 CEP 12 韩文输入，与本机 AE / CEP / 微软拼音的故障相似，但不能单独证明根因完全相同。微软提供[临时兼容模式](https://support.microsoft.com/zh-CN/Windows/Hardware/Input-Devices/microsoft-simplified-chinese-ime)：微软拼音设置 > 常规 > 兼容性 > 使用以前版本的微软拼音。此前已向用户提供步骤，尚无实测结果；本轮仍未修改系统设置。

参考：[CodeMirror 输入模式说明](https://codemirror.net/5/doc/manual.html#option_inputStyle)。第三方库文件保持原样。

## 工程整理目录、标签与方案保存

- 文件夹路径改为只读选择框，打开单列目录树后可搜索名称或完整路径，复用所有方案、全局目录及当前草稿中的目录层级。
- 选中父目录后「在当前目录新建」，只输入当前层名称，拒绝路径分隔符、点层级、控制字符与同路径重名。「新建并使用」或 Enter 一步更新规则，不再重复确认；实际 AE 目录仍在整理时创建。
- 2026-10-21 目录交互优化：双击目录直接使用，搜索结果或树中按 Enter 直接使用；关键词支持按路径多词匹配，完整路径和同名目录优先。无结果时 Enter 将搜索词带入新建表单，按 Enter 新建并使用。
- 搜索和新建共用底部的确认按钮，避免并列两套操作。Escape 先取消表单，再关闭弹层。打开目录树时定位当前目录，选中操作保留列表 DOM 和滚动位置；搜索结果区域保持高度，弹层不来回翻转。
- 「粘贴完整路径」保留高级录入，统一全角/半角斜杠、反斜杠、重复分隔符和各层首尾空白，校验非法路径。
- 后缀仍是单一内联输入框，无常用后缀列表或加号按钮。按 Enter 添加、失焦提交，支持点和通配符前缀、分隔列表、大写规范化与去重；非法项或跨规则冲突阻止保存和整理。
- 「忽略的合成名称」使用同款可删除标签，按 Enter 添加完整名称，按不区分大小写去重，保留名称中的空格。粘贴的逗号、分号或换行列表可添加多项。旧名单自动显示为标签，清空后保持空名单；模糊匹配仍为原有包含匹配。
- 输入法选词的 Enter 不提前生成标签。标签文本与 SVG × 通过 flex 居中，长名称允许折行。
- 方案下拉区分「内置预设」「我的方案」，移除独立名称输入框与三按钮行。内置预设显示「另存为我的方案」，个人方案显示「保存修改」，新草稿显示「保存方案」；旁边提示已保存、未保存或保存失败。
- 更多菜单提供新建、重命名、另存副本、删除，名称在弹窗中填写。新建为空草稿，首次保存前不写宿主；修改预设不覆盖内置数据。切换方案或新建前提示未保存修改，取消保留草稿，确认放弃恢复已保存版本。失败可重试，保存期间冻结编辑，成功后才更新基线。
- 「一键整理」执行当前规则，不顺带保存方案。全局文件夹与忽略名单继续即时保存，与方案保存状态独立。
- 旧方案的路径字符串、后缀数组及内部规则格式保持兼容。忽略名单设置兼容旧字符串和新字符串数组，备份可往返。
- 中英文、626px 与 360×520 面板均已检查；小面板可滚动，目录弹层保持在视口内。
