# 0.3.2 开发与验收

状态：**0.3.2 正式版**。用户已于 2026-10-20 确认界面并授权生成安装器、发布与更新官网。正式 changelog、CEP manifest、面板版本及中英文发布页统一为 0.3.2。

## 本阶段实现

- 表达式编辑器：行号，关键字/数字/字符串/注释/变量/属性分类着色，括号匹配和自动补全，自动缩进，Tab/Shift+Tab 缩进。
- 基础语法检查：350ms 输入延迟后检查，错误行标记及下划线，底部行列提示，点击跳转。检查未闭合括号、字符串、注释与非法语法等；允许 AE 全局名称和顶层 return，不在浏览器执行用户代码。实际 AE 属性、表达式引擎兼容性与运行结果由 AE 验证。
- 格式化按钮及 Shift+Alt+F，统一两空格缩进、空格与换行；通过语法树格式化保留字符串、注释和 ASI 语义。整次格式化可一次撤销；失败时原稿与撤销历史不变。
- 设置 > 通用设置 > 界面语言：简体中文 / English。覆盖导航、设置、操作反馈、确认/命名弹窗、内置条目、错误提示、历史更新日志与文件选择标题。语言选择随现有个人设置与备份保存。用户填写的名称、代码和路径保持原文。
- 顶部品牌保留原有图标，旁边文字使用独立文本，随语言切换显示「AE工具箱」/「AE Toolkit」。
- 沿用搜索/下拉选择、另存为、保存修改、删除、Ctrl/Cmd+Enter 应用、覆盖确认、安静模式和 AE 中的批次撤销。
- 所有编辑器、解析器和格式化依赖均在扩展内，支持离线运行，附固定版本与许可说明。

## 验证

执行命令（需要 Node；浏览器回归还需要 Playwright 与 Microsoft Edge）：

```text
node --test tests/*.test.cjs
node tests/browser.cjs
node tests/editor-browser.cjs
node tests/startup.cjs
node tests/navigation.cjs
```

单元测试覆盖语法定位、不执行代码、格式化前后语法树一致、ASI/字符串/正则/注释、格式化幂等、语言保存/导出/导入、翻译覆盖及旧数据兼容。编辑器浏览器回归覆盖真实键盘输入、括号补全、缩进、格式化撤销、语法标记、双语切换、草稿/撤销历史保留、语言与自定义数据重开后恢复、离线加载以及 360×520 和 626×870 布局。截图写入 `.artifacts/0.3.2/`（不纳入发布）。

## 待 AE 内验收

- 在真实属性上应用格式化前后的表达式，确认数值与时间变化结果一致。

- 重开面板后语言和自定义表达式仍正确；用户确认界面与操作体验。

浏览器和 Node 模拟不能代替 AE 宿主验收。本次未自动在真实 AE 项目内执行表达式；界面已由用户确认。发布前执行自动回归与隔离安装、更新、卸载测试。
