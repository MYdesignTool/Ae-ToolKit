# 发布页视觉与动效

本站沿用静态 HTML / CSS / JavaScript，不引入额外运行时依赖。扩展面板功能与版本号仍为 0.3.1；安装器按系统级目录修正，见安装说明。

- 品牌统一：`assets/img/logo.svg` 将工具箱头图中的蓝色折带 A 重新绘制为矢量，用于导航、页脚、favicon、静态回退和粒子采样；移除旧 Ae 占位标志。
- 粒子 Logo：约 34,000 个静态顶点一次上传 WebGL；GPU 计算聚合、局部避让和最多四组点击涟漪。按住左键拖动使用八个轨迹点形成连续路径，沿滑动方向牵引粒子，并在路径两侧产生起伏，不复用点击涟漪。点击、轻触及回车仍可触发轻涟漪；无 WebGL 或上下文丢失时显示同一矢量标志，上下文恢复后重建渲染。
- 标题流光：指针靠近标题时，仅在字面笔画内出现柔和的蓝紫高光，跟随并淡出；不绘制圆形反色区域。装饰副本对辅助技术隐藏，不影响标题语义。
- 玻璃：圆角距离场生成边缘法线位移图，结合背景模糊、斜向反光带与随指针变化的边缘高光。高光在进入、快速转向和离开时都从当前位置缓动，离开时淡出。支持 SVG backdrop-filter 的浏览器增加边缘折射，其他浏览器使用 CSS 模糊与高光；按可见区域和实际尺寸更新位移图。
- 氛围：缓慢流动的蓝紫光场、卡片轻微倾斜、主题切换圆形展开。页面隐藏时暂停背景动画；Logo 离开视口或页面隐藏时停止逐帧渲染。减少动态效果时使用静态标志与背景，触摸拖动仍可滚动页面。

参考 [DeepSeek 首页](https://www.deepseek.com/) 的标题邻近显现、局部变色交互形式；本站文字高光、粒子着色器、品牌图形、折射法线与动效代码独立实现。视觉与布局仍沿用工具箱的蓝紫主题。

检查：提供 Playwright 并安装 Edge 后运行 `node tests/site.cjs` 与 `node tests/visuals.cjs`。前者覆盖明暗主题、菜单、滚动返回、统一版本信息与响应布局；后者覆盖真实 WebGL 编译/绘制、输入与涟漪数量上限、键盘触发、快速主题切换、离屏/减少动效暂停、GPU 上下文恢复、静态回退和手机触摸滚动。截图输出到忽略目录 `.artifacts/interactive-glass/`。本轮浏览器验证使用 Windows Edge；其他浏览器按能力降级，尚未进行实机验证。

人设以透明 WebP 用于更新卡片下沿和安装标题旁，图片的下沿及右侧通过 CSS 遮罩柔化。返回顶部使用独立的固定火箭按钮，滚动超过 max(420px, 视口高度的 60%) 后出现在右下角；顶部隐藏时不可聚焦，点击后把焦点移回标题。减少动态效果时关闭位移并直接返回顶部。

功能卡由 HTML / CSS / SVG 直接绘制素材分类、批量表达式和脚本收藏三个示意，随主题自动适配；移除六张面板截图、图片放大和预览主题同步代码。扩展本体主题留待后续研究。窄屏首屏将粒子放到文字后方，降低透明度并淡出下缘，移除独立圆盘与重复标签，按钮仍位于前景。宽屏保留左右布局。交互由首屏容器接收，背景不会截获下载或导航点击。

扩展内更新日志复用发布页扒边素材，版本与日志条目保持原样。素材生成记录见 artwork.md。
