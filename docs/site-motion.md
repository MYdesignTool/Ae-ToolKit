# 发布页视觉与动效

本站沿用静态 HTML / CSS / JavaScript，不引入额外运行时依赖。扩展面板功能与版本号仍为 0.3.1；安装器按系统级目录修正，见安装说明。

- 品牌统一：`assets/img/logo.svg` 将工具箱头图中的蓝色折带 A 重新绘制为矢量，用于导航、页脚、favicon、静态回退和粒子采样；移除旧 Ae 占位标志。
- 粒子 Logo：约 17,000 个静态顶点一次上传 WebGL；GPU 计算聚合、局部避让和最多四组径向涟漪。点击、轻触及回车均可触发；无 WebGL 或上下文丢失时显示同一矢量标志，上下文恢复后重建渲染。
- 标题流光：指针靠近标题时，仅在字面笔画内出现柔和的蓝紫高光，跟随并淡出；不绘制圆形反色区域。装饰副本对辅助技术隐藏，不影响标题语义。
- 玻璃：圆角距离场生成边缘法线位移图，结合背景模糊、细边反射与鼠标高光。支持 SVG backdrop-filter 的浏览器增加边缘折射，其他浏览器使用 CSS 模糊与高光；按可见区域和实际尺寸更新位移图。
- 氛围：缓慢流动的蓝紫光场、卡片轻微倾斜、主题切换圆形展开。页面隐藏时暂停背景动画；Logo 离开视口或页面隐藏时停止逐帧渲染。减少动态效果时使用静态标志与背景，触摸拖动仍可滚动页面。

参考 [DeepSeek 首页](https://www.deepseek.com/) 的标题邻近显现、局部变色交互形式；本站文字高光、粒子着色器、品牌图形、折射法线与动效代码独立实现。视觉与布局仍沿用工具箱的蓝紫主题。

检查：提供 Playwright 并安装 Edge 后运行 `node tests/site.cjs` 与 `node tests/visuals.cjs`。前者覆盖明暗主题、菜单、预览、离线下载信息与响应布局；后者覆盖真实 WebGL 编译/绘制、输入与涟漪数量上限、键盘触发、快速主题切换、离屏/减少动效暂停、GPU 上下文恢复、静态回退和手机触摸滚动。截图输出到忽略目录 `.artifacts/interactive-glass/`。本轮浏览器验证使用 Windows Edge；其他浏览器按能力降级，尚未进行实机验证。

人设以透明 WebP 用于更新卡片下沿、安装提示侧边和页脚火箭返回顶部按钮。减少动态效果时关闭位移动效，返回顶部直接跳转；键盘操作把焦点移到首屏标题。浅色面板图仅用于发布页功能示意，通过 tests/panel-preview-light.css 生成；扩展本体主题留待后续研究。`node tests/site.cjs --update-light-previews` 重建这三张浅色图，原有 `--update-previews` 重建深色截图。素材生成记录见 artwork.md。
