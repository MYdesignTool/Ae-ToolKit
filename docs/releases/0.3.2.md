# AE Local Toolkit v0.3.2

## 中文

### 本次更新

- 新增表达式代码编辑器，支持语法高亮、行号、括号匹配与补全、自动缩进。
- 新增基础语法检查与错误行列定位，点击提示可跳转到错误位置。
- 新增一键格式化与 Shift+Alt+F 快捷键，支持一次撤销；语法错误时保留原稿。
- 新增简体中文 / English 界面切换，覆盖顶部品牌、设置、操作反馈、弹窗和更新日志，并记忆语言选择。
- 切换语言保留未保存的表达式、撤销历史与整理规则；用户名称、路径及代码保持原文。
- 编辑器、解析器和格式化工具随扩展本地分发，无需联网；保持 AE 2023 / CEP 11 及更新版本支持。

### 安装与更新

- Windows：下载 `aetoolkit-v0.3.2-installer.exe`。更新前关闭 AE，直接运行安装器，无需卸载旧版；安装器先备份个人数据，再更新程序。
- 手动安装 / macOS：下载 `aetoolkit-extension.zip`，使用其中的 `AeLocalToolkit/`。合并覆盖程序文件，保留原有 `data/user-data.json` 与 `backups/`。
- 支持 AE 2023 / CEP 11 及更新版本。未签名扩展需启用 CEP 开发模式；Windows 安装器可在组件页勾选。下载文件校验值见 `SHA256SUMS.txt`。

## English

### What’s new

- Add an expression code editor with syntax highlighting, line numbers, bracket matching and completion, and automatic indentation.
- Add basic syntax checks with line and column diagnostics. Click a diagnostic to jump to the error.
- Add one-click formatting and the Shift+Alt+F shortcut, with single-step undo. Invalid drafts remain unchanged.
- Add Simplified Chinese / English switching for the brand wordmark, settings, feedback, dialogs and changelog, with a saved language preference.
- Preserve unsaved expressions, undo history and organizer rules when switching languages. Keep user names, paths and code unchanged.
- Bundle the editor, parser and formatter locally for offline use. Retain support for AE 2023 / CEP 11 and later.

### Install and update

- Windows: download `aetoolkit-v0.3.2-installer.exe`. Close AE and run the installer directly, without uninstalling the previous version. The installer backs up personal data before updating program files.
- Manual installation / macOS: download `aetoolkit-extension.zip` and use its `AeLocalToolkit/` folder. Merge program files while keeping existing `data/user-data.json` and `backups/`.
- Supports AE 2023 / CEP 11 and later. Enable CEP development mode for this unsigned extension; the Windows installer offers it on the components page. Verify downloads with `SHA256SUMS.txt`.
