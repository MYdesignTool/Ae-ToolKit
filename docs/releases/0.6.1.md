# AE Local Toolkit 0.6.1

## 中文

- 新增离线表达式代码补全，从首字母开始匹配，输入和删除时持续更新，最多展示最匹配的 7 个候选。
- 补全覆盖常用 AE 全局对象、内置函数、成员链、JavaScript 常用项与当前草稿变量；函数自动补括号并支持单步撤销。
- 内置函数与属性提供精简双语帮助，展示用途、参数数量与含义、必填/可选参数和默认值。
- 新增独立的表达式编辑设置，补全和说明默认开启；接受候选按键可选 Enter 或 Tab，默认 Enter，并保存偏好。
- 仅选中图层时，可将表达式批量应用到自选变换属性；明确选中的具体属性始终优先，兼容 2D/3D 与分离位置各轴。
- 变换目标悬停展开、移开收起并保留勾选；默认全部不选，只在同次面板会话保留，重载面板后清空。
- 标签筛选支持多选，结果须同时包含全部所选标签，并可与名称搜索组合；标签块可逐个移除或一键清空。
- 保存自定义表达式时支持选择已有标签，也可输入后按 Enter 添加新标签，支持去重、逐项移除与取消修改。
- 表达式选择列表与当前选中项使用名称左对齐、标签块右对齐的布局，适配中英文和窄面板。
- 下拉菜单、补全弹层和整理目录选择新增进出动画，统一跟随动画耗时倍率、关闭动画与系统减少动态效果设置。
- 整理方案新增放弃修改并还原；保存和还原按钮仅在有未保存修改时显示，非安静模式下还原前确认。
- 未选属性、未勾选可用目标等情况显示醒目的红色错误提示；完善属性选择同步、宿主重载与快速开关弹层的状态处理。

Windows x64：退出 AE 后选择 Support Files，安装至 Plug-ins/AeltToolkitWebView2；macOS：使用 CEP ZIP。首次升级会保留旧 CEP、备份并迁移其数据；已有原生数据优先。脚本留在原位置，相对路径会重定位。

## English

- Add offline expression completion from the first letter. Refresh suggestions while typing or deleting and show up to seven best matches.
- Complete common AE globals, built-in functions, member chains, JavaScript entries and draft variables. Insert function parentheses with single-step undo.
- Show concise bilingual function and property help, including purpose, argument counts and meanings, required/optional parameters and defaults.
- Add dedicated expression editor settings. Completion and help default on; choose Enter or Tab to accept suggestions, with Enter as the default and preferences saved.
- When only layers are selected, batch-apply expressions to chosen transforms. Explicit property selections always take priority; handle mixed 2D/3D layers and separated Position axes.
- Open transform targets on hover and keep choices when the pointer leaves. Start with none selected, retain choices only for the panel session and clear them on reload.
- Filter by multiple tags, requiring every selected tag and optionally a matching name. Remove selected tag chips individually or clear them together.
- Choose existing tags when saving custom expressions or type new tags and press Enter. Deduplicate tags, remove them individually and discard edits on cancel.
- Align expression names to the left and tag chips to the right in the dropdown and selected value, with bilingual and compact layouts.
- Animate dropdowns, completion popups and organizer folder pickers on entry and exit, respecting the duration scale, Off and system reduced motion.
- Add discard and restore for organizer schemes. Show save and restore only for unsaved edits and confirm restoration unless Quiet mode is enabled.
- Show prominent red errors for empty property selections and unavailable targets. Improve selection synchronization, host reloads and rapidly reopened popups.

Windows x64: close AE, select Support Files, and install to Plug-ins/AeltToolkitWebView2. macOS: use the CEP ZIP. First upgrades back up and migrate legacy CEP data; existing native data takes precedence. Legacy CEP and personal scripts are retained. Relative script paths are rebased.
