| 原问题 | 处理 |

| 表达式失败也可能提示成功、目标可能变化 | 保留原有覆盖确认及安静模式；执行前校验目标签名，错误尝试回滚，部分失败如实汇总 |
| 表达式布局拥挤、确认按钮被挤压 | 保留下拉选择、代码编辑与命名弹窗；搜索和选择同行、编辑区伸缩，确认标题正文与按钮分开排列 |

| ExtendScript 图片路径不能直接作为浏览器地址 | 原生路径转 file URL；相对所选根目录优先查找 image 子目录与扁平图片，再回退脚本旁，多格式及项目原有 PNG 占位 |
| 递归扫描无边界、运行参数过宽 | 有限扫描、已扫描脚本集合校验 |
| 历史 CSS、状态和无引用函数残留 | 清理无引用样式、无用状态及辅助函数；保留原有必要的命名弹窗与功能取舍 |
| 发布页宣传图不统一、Canvas 持续重绘 | 面板示例预览、点击放大、减少动态效果；移除持续 Canvas 和外部高亮依赖 |
| 移动菜单收起仍遮挡按钮、复制失败提示成功 | 显示状态和指针事件同步，剪贴板失败如实反馈 |
| Jekyll 对整个仓库构建 | 纯静态白名单，仅发布 index.html 与 assets/ |
| 安装器批量改系统调试设置、任意目录递归卸载 | 可选当前用户调试组件；旧数据复制后保留，旧清单校验 ID 后停用；更新先备份、程序和内置数据白名单覆盖，卸载保留数据 |
| 构建器自动下载并静默安装依赖 | 显式要求 NSIS，版本源与清单校验，输出 SHA256 |
| 文档版本和宿主限制失真 | 更新 AE 2023 / CEP 11 基线、CEP 12 兼容说明及官方用户级目录说明 |

界面保留原有横幅列表、下拉选择与命名弹窗。图片和占位统一为 4:1 的圆角区域，名称固定起点；表达式保存按钮集中在编辑区标题旁。

## 验证

- 34 项 Node 回归：严格 JSON、特殊字符桥接、日志注入、配置迁移、磁盘失败与恢复、保存并发、真实主机初始化及模块静默失败检测、整理分类、脚本匹配、批量表达式跳过与回滚、统一数据的迁移及整目录移动、设置方案互不覆盖、导入整体回滚。
- Playwright 使用模拟 CEP 桥接检查原有下拉选择、覆盖确认、错误提示、草稿保护、命名保存、搜索、脚本双击、图片失败占位、窄面板和宽面板、明暗主题、复制失败、图片放大与移动菜单。
- 只读扫描用户脚本目录：108 个脚本，106 个匹配图片均在浏览器成功加载，另 2 个显示原有占位图；108 行的图片尺寸、8px 圆角、行高和名称对齐均在 626px、360px 面板检查；没有修改脚本目录，也没有将其绝对路径写入产品代码。
- 使用实际 NSIS 源码的隔离构建执行旧版迁移、重复更新和卸载：个人数据逐字节保留，备份失败时更新停止；测试包不写注册表，不接触真实安装目录。正式 NSIS 编译及 ZIP 白名单检查。未运行正式安装包、未部署或发布。

运行：`node --test tests/*.test.cjs`。浏览器：先提供 Playwright，再执行 `node tests/browser.cjs`。`ARTIFACT_DIR` 指定截图目录；`UPDATE_PREVIEWS=1` 显式更新发布页示例图片。可用浏览器需安装 Microsoft Edge。

## 必须在宿主验证的项目

本轮没有接入真实 AE。最低版本和新版宿主的加载、图层属性选择、表达式求值与错误恢复、撤销组行为、JSXBIN 执行、真实脚本写文件权限需要在 AE 中验证；浏览器和 Node 模拟不等于宿主认证。

建议使用工程副本，分别在 AE 2023 和一个 CEP 12 宿主检查：首次安装与旧版升级、无工程或无属性选择、已有表达式的覆盖确认与取消、错误表达式恢复、整理后撤销、中文与百分号路径、同名脚本图片、关闭面板前保存、备份导入导出。macOS 安装和路径尚未实测。

同一扩展目录被多个 AE 实例同时编辑时仍以最后保存为准；更新前需关闭 AE。外部脚本文件不会包含在配置中，扩展内脚本可通过相对路径随目录移动。当前 ZIP/安装器未经 CEP 签名，开发模式需显式启用。
