Ready when you areA few steps to your AE.

Supports After Effects 2023 and later. The Windows installer is recommended; macOS uses manual installation.

Before installing (required for both methods): This tool writes local files to organize assets and save presets and custom expressions. Enable script write access in After Effects 2023+:
Chinese UI: 编辑 → 首选项 → 脚本与表达式 → 勾选「允许脚本写入文件和访问网络」
English UI: Edit → Preferences → Scripting & Expressions → Check "Allow Scripts to Write Files and Access Network"
Restart After Effects for the setting to take effect. The core tools work offline; this option allows local file writing.

Method 1 · One-click installer Recommended for Windows

01

Download the installer

From GitHub Releases, download the Windows installer aetoolkit-*.exe.

02

Run the setup wizard

The current Windows installer is not code-signed. If Windows displays “Windows protected your PC”, confirm that the installer came from this project’s GitHub Releases, then click “More info” → “Run anyway” to continue.

Close AE before updating, then run the new installer without uninstalling first. The wizard backs up data before updating program files, keeping settings and presets in the extension folder. Installation uses the system-wide CEP directory and requires administrator approval. Data from an old user-level installation is migrated and backed up. For an unsigned development package, select development mode on the components page.

03

Open the panel

Restart After Effects as prompted, then open the panel from:

Window → Extensions → AE Local Toolkit

Check the download source and version before installing, and follow your organization’s installation policy when responding to system prompts.

Method 2 · Manual installation All platforms

01

Download and extract

From GitHub Releases, download the clean extension package aetoolkit-extension.zip and extract the AeLocalToolkit/ folder.

02

Copy to the extensions directory

Copy the entire AeLocalToolkit/ folder into the CEP extensions directory. Use the system-wide paths below; administrator privileges are required. Avoid keeping multiple copies of the extension with the same ID:

# Windows — system-wide
C:\Program Files (x86)\Common Files\Adobe\CEP\extensions\

# macOS — system-wide
/Library/Application Support/Adobe/CEP/extensions/

After copying manually, give the current user Modify permission on the extension’s data folder so settings and presets can be saved. The Windows installer handles this permission automatically.

03

Enable debug mode (for unsigned packages)

Unsigned development packages require debug mode for the matching CEP version. AE 2023/2024 uses CSXS.11; AE 2025 and later uses CSXS.12. Signed CEP extensions do not need this setting:

# Windows registry (current user, string value)
HKEY_CURRENT_USER\Software\Adobe\CSXS.11\PlayerDebugMode = 1

# macOS Terminal
defaults write com.adobe.CSXS.11 PlayerDebugMode -bool true
04

Open the panel

Restart After Effects, then open the panel from:

Window → Extensions → AeLocalToolkit
