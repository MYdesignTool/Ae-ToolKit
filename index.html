准备好，就开始几步，接入你的 AE。

支持 After Effects 2023 及更新版本。Windows 推荐安装器，macOS 可使用手动安装。

安装前必读（两种方式均需要）：本工具会在本地写入文件（整理素材、保存方案与自定义表达式），需开启 AE 脚本写权限。打开 After Effects 2023+：
中文：编辑 → 首选项 → 脚本与表达式 → 勾选「允许脚本写入文件和访问网络」
English：Edit → Preferences → Scripting & Expressions → Check "Allow Scripts to Write Files and Access Network"
重启 After Effects 使设置生效。工具的核心功能离线运行；此选项用于允许本地文件写入。

方式一 · 一键安装器 Windows 推荐

01

下载安装器

在 GitHub Releases 下载单个 Windows 安装器 aetoolkit-installer.exe。

02

运行安装向导

更新前关闭 AE，直接运行新版安装器，无需卸载。向导先备份数据，再更新程序，设置与预设保留在扩展文件夹中。安装到系统级 CEP 目录，需要管理员授权；旧用户级数据会迁移并备份。未签名开发包需在组件页选择开发模式。

03

打开面板

按提示重启 After Effects，通过菜单路径打开面板：

窗口(W) → 扩展 → AE Local Toolkit

安装前请核对下载来源与版本，按组织的安装策略处理系统提示。

方式二 · 手动安装 全平台

01

下载解压

从 GitHub Releases 下载干净扩展包 aetoolkit-extension.zip，解压得到 AeLocalToolkit/ 文件夹。

02

复制到扩展目录

将 AeLocalToolkit/ 文件夹整体复制到 CEP 扩展目录。统一使用以下系统级目录，复制时需要管理员权限。避免同时保留多个同 ID 的扩展副本：

# Windows 系统级
C:\Program Files (x86)\Common Files\Adobe\CEP\extensions\

# macOS 系统级
/Library/Application Support/Adobe/CEP/extensions/

手动复制后，给扩展内 data 文件夹设置当前用户的修改权限，供设置与预设保存。Windows 安装器会自动处理此权限。

03

开启调试模式（未签名时）

未签名开发包需开启对应 CEP 版本的调试模式。AE 2023/2024 使用 CSXS.11，AE 2025 起使用 CSXS.12。已签名 CEP 扩展不需要此设置：

# Windows 注册表（当前用户，字符串值）
HKEY_CURRENT_USER\Software\Adobe\CSXS.11\PlayerDebugMode = 1

# macOS 终端
defaults write com.adobe.CSXS.11 PlayerDebugMode -bool true
04

打开面板

重启 After Effects 后，通过菜单路径打开面板：

窗口(W) → 扩展 → AeLocalToolkit
