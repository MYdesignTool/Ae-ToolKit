// 核心功能

三大模块覆盖素材管理、代码复用与工作流加速

📁 项目整理器

按预设规则自动分类素材（图片、视频、音频、PSD、3D 等）。支持自定义多方案与嵌套文件夹结构，整理完成后自动清除空文件夹。

  • 智能识别媒体类型
  • 自定义整理方案
  • 自动清理空目录

⚡ 表达式管理器

批量应用或移除 After Effects 表达式，内置示例库。支持用户自定义表达式收藏、搜索与编辑，操作前确认覆盖或删除。

  • 一键批量操作
  • 自定义表达式库
  • 安全确认机制

▶️ 脚本启动器

浏览并运行本地 .jsx / .jsxbin 脚本文件。支持收藏夹、实时搜索过滤、仅显示收藏项，并自动关联显示 PNG 图标。

  • 快速启动任意脚本
  • 收藏夹与搜索
  • PNG 图标关联

# 安装指南

两种方式任选其一，Windows 用户推荐安装器

方式一 · 一键安装器 Windows 推荐

01

下载安装器

在 GitHub Releases 下载单个 Windows 安装器 aetoolkit-installer.exe。

02

运行安装向导

双击运行，按原生向导操作：阅读许可协议并勾选同意 → 确认安装路径（默认已填好用户级 CEP 目录，可「浏览…」自定义）→ 点击「安装」。安装器会自动写入 PlayerDebugMode，无需管理员权限。

03

打开面板

按提示重启 After Effects，通过菜单路径打开面板：

窗口(W) → 扩展 → AE Local Toolkit

💡 若系统提示「未知发布者」属正常现象（安装器未做代码签名），点「更多信息 → 仍要运行」即可。

方式二 · 手动安装 全平台

01

下载解压

从 GitHub Releases 下载干净扩展包 aetoolkit-extension.zip，解压得到 AeLocalToolkit/ 文件夹。

02

复制到扩展目录

将 AeLocalToolkit/ 文件夹整体复制到 CEP 扩展目录：

# Windows 用户级（无需管理员）
%APPDATA%\Adobe\CEP\extensions\

# Windows 系统级
C:\Program Files (x86)\Common Files\Adobe\CEP\extensions\

# macOS 用户级
~/Library/Application Support/Adobe/CEP/extensions\

# macOS 系统级（需管理员）
/Library/Application Support/Adobe/CEP/extensions\
03

开启调试模式（未签名时）

若扩展未签名（通常已通过安装器或旧版写入，可跳过），需手动开启调试模式以加载未签名扩展：

# Windows 注册表
HKEY_CURRENT_USER\Software\Adobe\CSXS.9\PlayerDebugMode = 1

# macOS 终端
defaults write com.adobe.CSXS.9 PlayerDebugMode -bool true
04

打开面板

重启 After Effects 后，通过菜单路径打开面板：

窗口(W) → 扩展 → AeLocalToolkit

⚠️ 重要（两种方式均需要）：本工具会在本地写入文件（整理素材、保存方案与自定义表达式），需开启 AE 脚本写权限。打开 After Effects 2020+：
中文：编辑 → 首选项 → 脚本与表达式 → 勾选「允许脚本写入文件和访问网络」
English：Edit → Preferences → Scripting & Expressions → Check "Allow Scripts to Write Files and Access Network"
重启 After Effects 使设置生效。工具完全离线运行，不访问任何网络，该权限仅用于开放本地文件写入。
